# Mobile Shop (Frontend)

This is a simple Next.js + TypeScript frontend for a mobile shop (static data).

Quick start:

1. npm install
2. npm run dev

What I implemented:
- Home page with product grid
- Products listing
- Product detail pages (add to cart)
- Client-side cart (localStorage) and simulated checkout
- Tailwind setup (config + directives)

Next recommended steps:
- Add images and branding
- Integrate a backend/Stripe for real checkout
- Improve accessibility and responsiveness
